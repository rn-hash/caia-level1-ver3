## 📖 学習の進め方（1週間プラン）

### 前提: コーチマニュアル（COACH_MANUAL.md）を最初の30分で通読
七つの武器（消去法・絶対表現・キーワード一致・電卓操作）を理解してから問題演習に入る。

### 1日目: 得点源の確保（Ethics + Intro）
- 06_ethics.md（20問）: 最も確実に取れる。**全問正解を狙う**
- 01_introduction.md（48問）: 配分最大トピック。概念を固める
- 秒殺テクを読みながら「なぜこの選択肢か」を必ず確認

### 2日目: Hedge Funds（34問）— 最重要トピック
- 報酬計算（2/20・HWM・ハードル）は電卓手順を身体化
- 戦略分類（ロング/ショート・イベントドリブン・マクロ・レラティブバリュー・CTA）
- 統計バイアス（サバイバーシップ・バックフィル）は武器7で暗記

### 3日目: Real Assets（34問）+ PE（20問）
- Real Assets: コンタンゴ/バックワーデーション・ロールイールド・キャップレート
- PE: ウォーターフォール・キャリー・IRR・DPI/TVPI/RVPI・Jカーブ
- 追加のPE経済学9問（new_01）もこの日

### 4日目: Private Debt（28問）+ 統計（new_02 9問）
- PD: メザニン・ユニトランシュ・CDO/CDS・キャットボンド・コベナンツ
- 統計: 回帰・仮説検定・スピアマン・情報レシオ（計算多め）

### 5日目: Digital（12問）+ デリバティブ（new_03 8問）+ その他
- Digital: ビットコイン・PoW/PoS・DeFi
- デリバティブ: グリークス・コストオブキャリー・プットコールパリティ
- 統合問題（ver1_integrated 7問）

### 6日目: 総復習 + 弱点補強
- 全ファイルの「秒殺テク」だけを読み返す（問題を解かずに）
- 間違えた問題を重点的に再演習

### 7日目: 最終確認
- COACH_MANUAL.md を再読
- 電卓操作を一通り復習
- 正解分布・頻出パターンを最終確認
