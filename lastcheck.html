🛡️ 本番ひっかけ対策 トップ10

  • 「always / never / all / must」はほぼ誤答。消去候補の最優先
  • LEAST / NOT / EXCEPT問題→「明らかに正しい・当たり前」の選択肢が答え
  • 「most likely / best describes」→消去法で2つに絞ったら勘で決めない。用語の定義と合う方
  • 時間切れは71秒/問（200問・4時間）。1問3分迷ったらマークして飛ばす
  • 計算問題で選択肢が倍率（10% vs 0.1）なら単位・年複利/期間複利を先に確認
  • IRRは符号変化2回以上で複数解。ESG/限定キャッシュフロー問題はBA II Plusで直接解かず式で
  • 分散＝標準偏差の2乗。標準偏差を年換算×√T、分散は×T（季節データ→年次は√4=2倍）
  • シャープレシオは分子に無リスク金利を引く。情報レシオはベンチマークを引く（分母はトラッキングエラー）
  • プットコールパリティ: S + P = C + PV(X)。移項して各ポジション（covered call = S−C等）を即合成
  • 倫理問題は「開示・利益相反の回避」が最善解。贈答品は原則断る

📊 統計

歪度 S>0＝右に長い裾（平均＞中央値）｜S=Σ((x−μ)/σ)³/n
⚠️ 右裾＝「大きなプラス外れ値あり」
尖度 K>3＝正規より尖る（裾が厚い）｜超過尖度=K−3
相関 r = Cov/(σx·σy)｜σx=√Vx
⚠️ 外れ値1つで小サンプルのrは0方向へ崩れる
Spearman順位相関=通常のrを「順位」に適用｜外れ値に強い・非線形単調関係OK
Durbin-Watson ≈2で自己相関なし｜0に近い=正、4に近い=負の自己相関
Jarque-Bera: 正規なら JB≈0｜歪度＋尖度の検定。棄却→正規でない
2資産分散: σp² = w1²σ1² + w2²σ2² + 2w1w2·ρ·σ1σ2
⚠️ ρ<1で分散効果。ρ=−1で完全ヘッジ
N資産等分の分散=σ²/N + (N−1)/N·平均共分散｜N→∞で共分散項のみ残る

💰 PE・ファンド報酬

2&20: 総報酬 = 2%×NAV + 20%×(リターン−管理費後利益)｜HWM超えた分のみ
ハードル: hard＝開始資産にのみ適用 / soft＝運用利益全体に適用
⚠️ soft/hardの違いは計算問題の最頻ひっかけ
Full catch-up: ハードル分をGPが全取り→ (利益)×20%でGPが取れる水準までLPに分配後にGPへ
Clawback: 終了時にLPへ GP報酬返還｜前期で過大配分→後期で調整
ウォーターフォール: ①リターン・オブ・キャピタル→②優先リターン→③キャッチアップ→④80/20分割の順
MIRR: プラスCFは再投資率rで終端複利→マイナスCFはrで現在価値→IRR計算
BA II: CF登録→NPV(I=r)→終端値→IRR
DPI=実現分配/払込, TVPI=(分配+残存NAV)/払込, RVPI=残存NAV/払込

📈 デリバティブ・金利

プットコールパリティ: S + P = C + PV(X)｜covered call = S − C = −P + PV(X)
コストオブキャリー: F = S·e^((r+u−y)T)｜u=保管費, y=利便収益（コンビニエンス・イールド）
F > S(期近): コンタンゴ / F < S: バックワーデーション
⚠️ ロールリターン: コンタンゴ=マイナス要因
ゼロクーポン債価格 = FV/(1+y)ᵀ｜デュレーション=残存年限（ゼロ債のみ）
デュレーション: ΔP/P ≈ −D·Δy｜複数債ポートフォリオD=加重平均
B-S: C = S·N(d1) − X·e^(−rT)·N(d2)｜増加要因=S, σ, T, r（コール）。プットはX, σ, T, r↑で↑・S↓で↑

🏗️ 不動産・実務

Cap rate = NOI / 価値｜リスク高い物件（郊外・テナント不安定）ほどCap rate高い
ローリング=満期の異なる先物を買い継ぎ｜コンタンゴ市場でのロールは損失要因
IRRの弱点: 再投資率仮定・複数解・規模無視｜MIRRで改善
シャープ = (Rp−rf)/σp｜情報レシオ = (Rp−Rb)/σ(Rp−Rb)
